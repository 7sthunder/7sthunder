## About

I work end to end — data model, API, interface, and the pipeline that keeps it running. Recent work
spans document forensics, clinical adherence tooling, and multi-tenant operations platforms for
A S CodeLabs clients.

- **Document forensics** — [DocuVerify](https://github.com/7sthunder/DocuVerify) measures where a

- **Health tooling** — [MediTrack AI](https://github.com/7sthunder/medvault) turns medication schedules
  into an adherence record with a caregiver loop, on a strict TypeScript domain layer.
- **Operational platforms** — transport, print production, recruitment, and gym systems running on
  Cloudflare and Postgres.

Much of this work is private because it belongs to clients or to A S CodeLabs. The projects below
are the parts I can show publicly.

## Featured Projects

### [DocuVerify](https://github.com/7sthunder/DocuVerify)

Document authenticity and forgery detection built as an evidence platform rather than a binary
classifier. A PDF or image is ingested, run through a multi-signal forensic engine, and returned as
a 0–100 suspicion score with a LOW / MEDIUM / HIGH verdict and highlight boxes drawn on the
rendered page — every finding backed by a concrete measurement.

- **Deterministic signals** — layout grid alignment, font and size outliers, Laplacian sharpness for
  pasted-in patches, PDF producer and timestamp metadata, native-text-versus-OCR desynchronisation.
- **Domain verifiers** — arithmetic and field-consistency rules for invoices, certificates and tax
  forms, selected from a data-driven document taxonomy.
- **AI kept in bounds** — an optional OpenAI-compatible LLM pass re-reasons over fields the
  deterministic engine already extracted, is capped at 10% of the score, and is off by default.

### [MediTrack AI](https://github.com/7sthunder/medvault)

Medication adherence and tracking that answers two questions: what to take now, and how well the
schedule is being followed. Next.js App Router over a tRPC domain layer and a 17-table Postgres
schema, with a caregiver loop for escalations and shared visibility.

- **Strict domain core** — dose and adherence engines, schedule materialisation and reconciliation
  are pure functions under enforced coverage thresholds.
- **Phases 01–18 complete, quality sweep in progress** — 366 tests across 49 files green at 97.18%
  statement coverage, with typecheck, lint, format and build running in GitHub Actions CI.
- **Voice and AI at the edges** — Gemini-backed insights and speech intake, held to an explicit
  boundary: the system surfaces adherence patterns and never diagnoses or prescribes.

### [FairloanAI](https://github.com/a-s-codelabs/FairloanAI)

An AI loan negotiation workspace that turns long-form loan agreements into structured, comparable
data and simulates lender-versus-borrower negotiation, aligned to LMA Green Loan Principles and
documentation standards.

- **Simulation, not a black box** — both sides are analysed and scored for risk and satisfaction,
  then concessions and a suggested position are generated as structured output.
- **Remaining scope** — the side-by-side digital loan comparison dashboard is still planned.
